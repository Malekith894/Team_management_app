# Team Management Application

A responsive team and project management application inspired by tools like Microsoft Teams. The application is designed to help managers organize their teams, manage projects, assign tasks, and monitor project progress from a centralized dashboard.

## 🚀 Features

- **User Registration:** Sign-up functionality for users.
- **Team Management:** Add and manage team members.
- **Project Management:** Create and organize multiple projects.
- **Task Management:** Create and manage tasks associated with individual projects.
- **Centralized Management:** A unified interface for managers to monitor their teams, projects, and tasks.
- **State Management:** Context API and Redux for managing application state.
- **Local Data Persistence:** Uses LocalStorage to preserve application data.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Redux
- Context API
- Tailwind CSS
- CSS Modules
- LocalStorage

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Malekith894/Team_management_app.git
```

2. Navigate to the project directory:

```bash
cd Team_management_app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 💾 Data Persistence

Application data is stored in the browser's LocalStorage, allowing data to persist between page refreshes in the same browser.

## 🎯 Project Purpose

The main goal of this project was to build a practical team management application while applying modern React development concepts, including component-based architecture, global state management, reusable components, and responsive UI development.
